# Strange characters mod p for all primes p < 1000000.
# Derickx-Stoll, "Prime order torsion on elliptic curves over number fields, Part I: Asymptotics";
# for the definitions see Definition 5.1 there: a newform f of weight 2 for Gamma_1(p) with
# nontrivial character chi is strange if L(f, 1) = 0, and chi is strange if there is a strange
# newform with character chi; strdim(p) is the number of strange newforms of level p.
#
# One line per prime p and order n of a strange character (the even characters mod p of a given
# order n > 1, n | (p-1)/2, form one Galois orbit, and strangeness is Galois invariant):
#   p       the prime
#   order   the order n of the strange characters
#   strdim  the number of strange newforms of level p whose character has order n
#           (strdim(p) is the sum over the lines for p; only 8713 has two lines)
#
# Sources: p < 200000: Table 2 of the paper (TABLE2 in strange_primes.magma); 200000 < p < 1000000:
# the search on the HPC cluster lipwig of the University of Bayreuth (DFG funding number 422127126),
# October/November 2026, one job per pair (p, n) (see cluster/): with strange_primes.magma
# (search_pair.m) for p < about 450000, and with the sparse method of sparse/ (after F. Najman) for
# most pairs with larger p and for all pairs with p > 500000. Every candidate was verified in
# characteristic 0, with strange_primes.magma or with sparse/crt_verify.py. The search covers all
# pairs (p, n) and was complete for p < 1007089 on 2026-11-07, so the list is complete for p < 1000000.
